# office-financial-model

用户要做"预算、测算、投资回报、盈亏平衡、人力成本、项目收益、报价测算"这类"假设 → 计算 → 结论"的 Excel 时先读本技能：数字不能错，改一个假设整张表要跟着变。表格的基本操作见 `office-xlsx`，要从现成数据里取数时见 `office-report`。

## 铁律

1. **假设和计算分开**：所有输入（单价、数量、增长率、折现率、税率）只在 `假设` 工作表出现一次，计算处用公式引用。公式里除了 0、1、12 这类单位换算，不要夹带常数；同一个数字出现在两个地方，改一处漏一处就是事故。
2. **输入一眼能认出来**：输入格蓝色字（`font_color` 为 `#0000FF`）加浅黄底（`fill` 为 `#FFF2CC`），公式格保持黑字。用户一眼看出哪些格子能改。
3. **只用用户给的数**：没有的假设留空并写"待确认"，高亮出来，不要编；行业经验值要用，必须标明"这是估计"，让用户确认。
4. **单位统一**：金额统一一种单位（元或万元），写在表头；同一列不混用。百分比存小数，期间用真日期或统一的期号。

## 工作表结构

| 工作表 | 放什么 |
| --- | --- |
| `假设` | 输入。列：名称、数值、单位、来源或说明；有场景时每个假设三列（基准、乐观、悲观），再加一列"生效值" |
| `测算` | 按期间横向展开（年或月），每一行一个科目，全是公式；同一行的公式写法一致，方便 `fill_formula` 一次填满整个区域 |
| `汇总` | 结论：收入、成本、利润、现金流，以及 `NPV`、`IRR`、回收期、毛利率这类关键指标，加一行"关键假设" |
| `校验` | 勾稽检查：合计等于分项之和、期末等于期初加变动、收入减成本等于利润；每项一行，通过显示 `OK`，否则显示 `差异` |

校验总开关放在 `汇总` 顶部：`=IF(COUNTIF(校验!B:B,"差异")=0,"全部通过","有差异")`，用 `conditional_format` 让"有差异"变红。

## 场景和敏感性

- **场景**：`假设` 里放一个场景编号单元格（1 基准、2 乐观、3 悲观），"生效值"写成 `=CHOOSE($B$1,C5,D5,E5)`，计算处只引用生效值。
- **敏感性**：本工具没有模拟运算表。对两三个最关键的假设，各取上下 10%：每个情形用 `edit_xlsx` 的 `save_as` 写一份副本，`operations` 里用 `set_cell` 改那个假设，再 `read_xlsx` 读副本里的结果并记下来；全部做完，把这些结果写进原表 `汇总` 的"敏感性"小表，标明"静态结果，假设变了要重算"。副本放进单独的文件夹，并告诉用户可以删掉；原表的假设不要动。

## 常用公式

- 净现值：在 `测算` 里排成这几行（列 C 是期初，往右是第 1、2、3……期）：第 3 行期号（0、1、2……），第 5 行净现金流，第 6 行折现系数 `=1/(1+假设!$B$2)^C3`（折现率只放在 `假设` 里），第 7 行现值 `=C5*C6`；净现值 `=SUM(C7:H7)`，或一格写成 `=SUMPRODUCT(C5:H5,C6:H6)`。每一步都看得见，结果和 Excel 一致。
- **不要写 `=NPV(折现率,区域)`**：内置计算器把 `NPV` 的区域参数只当第一格算，`read_xlsx` 读回和文件里预存的结果都会是错的（Excel 打开重算是对的，但你没法核对，只看预览的人会看到错数）。一定要用 `NPV` 时，把每期现金流分别写成参数：`=C5+NPV(假设!$B$2,D5,E5,F5,G5,H5)`，`C5` 是期初那一笔，不放进 `NPV` 里。
- 内部收益率：`=IRR(C5:H5)`，现金流要有正有负，全是一个符号会出错。
- 等额还款：`=PMT(利率/12,期数,-本金)`，利率、期数的单位要对得上（年利率除以 12，期数按月）。
- 回收期：先加一行累计现金流，回收期（期数）= `=COUNTIF(累计行,"<0")+1`，现金流只由负转正一次时成立；要算到小数，在转正那一期按比例插值。
- 防出错：除法写 `=IFERROR(A5/B5,"")`，查找写 `=IFERROR(VLOOKUP(...),"待补充")`；不要让 `#DIV/0!` 留在成品里。

## 怎么做

1. 先和用户对一遍假设清单：每项的数值、单位、来源；缺的一次问完。
2. `create_xlsx` 建好四个工作表，写入 `假设` 并留好 `测算` 的表头。
3. 一次 `edit_xlsx` 写完公式和格式：`fill_formula` 填 `测算` 和 `汇总`，`format` 设输入格的颜色和数字格式，`col_width` 调列宽，`freeze` 冻结科目列和表头，`conditional_format` 给 `校验` 上色。
4. 需要图（收入利润趋势、现金流累计）时，用 `add_chart`，`data_range` 指向 `测算` 里带表头的区域。

## 验证（不做完不要交）

- `read_xlsx` 读回 `汇总` 和 `校验`：没有 `#DIV/0!`、`#REF!`、`#NAME?`、`#VALUE!`；校验全部 `OK`。
- 抽三五个数用心算或 `analyze_xlsx` 复核，量级要对（万元和元别差一万倍）。
- 改一个假设试一次（同样用 `save_as` 写副本，不动原表），关键指标应当按预期变化。
