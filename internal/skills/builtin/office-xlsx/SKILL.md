# office-xlsx

用 `create_xlsx`、`read_xlsx`、`edit_xlsx` 新建、读取、修改 Excel 工作簿：台账、预算、统计表、带公式和图表的报表。

## 新建：create_xlsx

- `sheets` 里每个工作表有 `name` 和 `rows`（一行一个数组）。第一行默认是表头，会加粗、着色、冻结并加筛选；不是表头时把 `header` 设为 false。
- **数字写成数值**，不要写成 `"1,234元"` 或 `"98%"` 这样的字符串，否则无法求和。单位放进表头（例如"金额(万元)"），百分比存 0.986 再设数字格式。
- 公式写成以 `=` 开头的字符串，函数用英文名：`=SUM(B2:B9)`、`=B2/C2`、`=IF(D2>0,"达标","未达标")`、`=VLOOKUP(A2,明细!A:C,3,FALSE)`。引用别的工作表用 `工作表名!A1`。
- 不要为了"好看"留空行、合并单元格做数据区；数据区保持一行一条记录，汇总行放在最后或另放一个工作表。
- 工作表名最多 31 个字，不能含 `\ / ? * [ ] :`。

## 读取：read_xlsx

1. 先只给 `relative_path` 调用一次：返回所有工作表名和已用区域，公式已经算出结果。
2. 大表用 `range`（如 `A1:H60`）和 `max_rows` 翻页，不要一次读完。
3. 找某个词在哪：用 `find`，可以限定 `sheet`，不限定就搜全部工作表。
4. 需要看公式本身时加 `formulas: true`。
5. 单元格显示成什么样（日期、百分比、千分位）就返回什么样。**显示的不一定是存的**：`95.8%` 存的可能是数值 0.958，`2026-09` 可能是真日期而不是文本。写公式、条件格式之前先 `analyze_xlsx` 看那一列的 `stored`（见下面"按真实存储写公式"）。
6. **几十行以上的表不要整表读**：整表一次读下来要占掉大量上下文，会话会被撑爆。先 `analyze_xlsx` 看结构（表头在哪一行、有哪些列、月份和地市怎么写），`read_xlsx` 只用 `range` 读十来行样例；要统计就交给 `analyze_xlsx`。
7. 合并单元格只有左上角有值，其余格读出来是空的；写公式引用这类列要小心（`analyze_xlsx` 已经把合并的值填到每一行）。

## 分析：analyze_xlsx

要合计、均值、排名、前后几名、未达标名单、比上月：用 `analyze_xlsx` 算，不要自己用 `read_xlsx` 读出来再心算。它会找表头、跳过标题行和合计行、把 `"93.8%"` 这类文本数字当数值读，并指出空白格。详细用法和写通报的做法见 `skill:office-report`。`read_xlsx` 给的是**显示出来的样子**（95.5%），`analyze_xlsx` 用的是**原始数值**（95.46%），排名和差值以后者为准。

## 修改：edit_xlsx

`operations` 按顺序执行，**任何一步失败整份都不保存**，错误信息会指出是第几个操作。就地修改前会自动在同目录留一个带时间戳的备份；想保留原件就用 `save_as` 另存。

| op | 用法 |
| --- | --- |
| `set_cell` | `cell` + `value`（数字、布尔、字符串；`=` 开头是公式；null 清空） |
| `set_range` | `cell` 为左上角，`rows` 为二维数组 |
| `clear_range` | `range` |
| `add_sheet` / `rename_sheet` / `delete_sheet` | `name`，改名和删除要给 `sheet` |
| `insert_rows` / `delete_rows` | `row`、`count` |
| `format` | `range` + `format`：`bold`、`italic`、`font_size`、`font_color`、`fill`（`#RRGGBB`）、`num_fmt`、`align`、`wrap`、`border` |
| `col_width` | `columns`（如 `A` 或 `A:C`）+ `width` |
| `merge` / `freeze` / `filter` | 合并、冻结窗格（`A2` 冻结首行）、筛选 |
| `add_chart` | `cell` 为图表左上角，`chart`：`type`、`data_range`、`title` |
| `delete_chart` | `cell` 填 `read_xlsx` 返回的图表 `anchor` |
| `fill_formula` | `range` + `formula`：公式按 `range` **左上角**那一格来写，会像 Excel 向下填充那样复制到整个区域，相对引用自动调整，`$` 锁定的不动。整列公式（环比、占比、达标判断）用它，不要一格一格 `set_cell`，也不要在 `set_range` 里塞几百个公式字符串 |
| `conditional_format` | `range` + `rule` + `format`：满足规则的格子自动变色，数据改了颜色跟着变。`rule.type` 是 `cell`（`criteria` 取 `>`、`<`、`>=`、`<=`、`=`、`!=`、`between`，配 `value`、`value2`）或 `formula`（`formula` 按 `range` 左上角来写，如 `=AND($B4=DATE(2026,9,1),$C4<0.96)`）；颜色写在 `format` 的 `fill`、`font_color`、`bold` 里。比较的是**存储值**：显示 96% 的格子存的是 0.96 |
| `copy_format` | `cell` 是样式来源，`range` 是要套用的区域：给新增的一列配上和相邻列一样的表头和边框样式（来源取 `H3`，目标填 `I3`；数据列同理），之后再用 `format` 改它的数字格式 |
| `to_number` | `range`：把用文本存的数字（`"93.8%"`、`"1,234"`、`"￥12"`）转成真数值，百分比保持原来的小数位显示。`007` 这类编号和非数字文本不动。公式要覆盖的列里有文本数字时先转，再写公式 |

改一份现成的表时：原文件要保留就用 `save_as` 另存（目标文件已存在时再加 `overwrite`）；先 `analyze_xlsx` 或 `read_xlsx` 弄清表头行号和数据区范围（标题行、说明行会让表头不在第一行），公式和格式都按真实行号写；把分析结果写进新工作表时，用 `add_sheet` 加表，再用 `set_range` 写入，排名、汇总这类数字从 `analyze_xlsx` 取，写成固定值并在表里注明统计口径；名次用它的 `rank`，数值相同的名次相同（并列），不要自己 1、2、3 往下编。

### 按真实存储写公式

`read_xlsx` 给的是显示值，公式比较的是存储值。先 `analyze_xlsx` 看每列的 `stored` 和 `issues`，再写：

- 百分比存的是小数：条件写 `$C4<0.96`（不是 `<96`），环比百分点写 `(C5-C4)*100`。
- 月份是真日期：判断某月写 `TEXT($B4,"yyyy-mm")="2026-09"` 或 `MONTH($B4)=9`，不能写 `$B4="2026-09"`。
- 缺数要先判断再算：`=IF(AND($A5=$A4,ISNUMBER($C4),ISNUMBER($C5)),($C5-$C4)*100,"")`；空白格会让相邻两行留空，这是对的，汇报时说明有几行因此留空。`issues` 里列出的文本数字格（如 `C142` 存成了 `"91.0%"`）是数据的一部分，不是缺数：同一次 `edit_xlsx` 里第一步先对那一列 `to_number`，再写公式，汇报时说明转换过。
- 公式、格式、新工作表放进**同一次** `edit_xlsx`，写完 `read_xlsx` 读回对一遍（每个地市第一个月是空的、没有 `#VALUE!`、数值量级对），不要靠一遍遍改公式试出来。

常用数字格式：`#,##0`（千分位）、`0.00`、`0.0%`、`yyyy-mm-dd`、`#,##0.00"元"`。

增删行时：

- 其他公式里指向下移单元格的引用会像 Excel 那样自动调整；但在求和区域的**紧下方**插入新行时，`=SUM(B2:B3)` 这类范围不会自动扩大，要自己改成覆盖新行。
- 插入的新行沿用上一行的单元格格式（数字格式、边框等）；紧挨表头下面插入时沿用下一行。写完数据后读回确认格式一致，不一致再用 `format` 补。

图表的 `data_range` 要包含表头行，第一列是分类，后面每一列成为一个系列，例如 `A1:D7`。`type` 可选 `column`、`stacked_column`、`bar`、`line`、`area`、`pie`、`doughnut`、`scatter`。图表放在数据右边空白处，别盖住数据。

### 工作表里已有图表

`read_xlsx` 会在结果的 `charts` 里列出所读工作表上的图表：`anchor`（左上角单元格）、`type`、`title`，以及每个系列取数的区域（`categories`、`values`）。

- **增删行不会改图表取数的区域，也不会移动图表。** 用户要求"数据加了一行，图表也要跟上"时，先看 `charts` 里的区域是不是还停在旧的行数。
- 让图表跟上数据：同一次 `operations` 里先 `delete_chart`（`cell` 用它的 `anchor`），再 `add_chart`（同一个 `cell`、同类型、同标题，`data_range` 换成新的）。重建的图表是默认样式，原来的颜色、字体不会保留，用户在意样式时先说一声。
- 同一个单元格上已经有图表时，`add_chart` 会报错，不会叠一个新的上去；不要靠"再加一个"来修图表，否则旧图还在，工作表里就有两个。
- 只是新增一个图表时，选一个空白单元格放，先看 `charts` 里已有图表的位置，别压在上面。

## 验证

改完立刻 `read_xlsx` 读回改动的区域：

- 公式单元格有没有出现 `#DIV/0!`、`#REF!`、`#NAME?`、`#VALUE!`，有就修公式再读一次；
- 求和、占比这类结果和手算的是否一致，不一致就说出差别；
- 新增的工作表、列宽是否符合预期；
- `charts` 里每个图表取数的区域是否覆盖了最新的数据行，数量是否是你想要的（没有重复）。

## 注意

- 文件里的公式结果会随文件一起保存，用 Excel 或 WPS 打开时还会重新计算；微信、资源管理器预览里也能看到数值。
- 编辑已有文件是"读入再写出"：数据透视表、切片器、宏、外部链接和个别特殊图表样式可能丢失。文件里有这些东西时，先告诉用户，并用 `save_as` 另存一份而不是就地改。
- 不要同时让用户在 Excel 里打开着同一个文件去改，文件被占用时写入会失败。
- 日期单元格如果用户给的是文本，保持原样，不要擅自转换；要转换先说明。
