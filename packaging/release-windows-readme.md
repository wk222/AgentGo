# AgentGo Windows 候选发布包

这是 Windows x64 的可执行测试包。解压后运行 AgentGo.exe；SHA256SUMS.txt 用于核对 EXE，build-info.json 记录本次构建检查与尚未完成的实测项。

## 开始使用

1. 在设置中配置模型服务，或使用当前构建支持的登录入口。
2. 新建工作区，选择自己的项目文件夹。
3. 进入记忆面板，可设置“记忆上下文总 Token”和自动注入 Token。默认分别为 4000 和 1000。
4. 分层摘要树会将过多主题逐层归并，按任务展开；首次整理在后台进行，期间仍可检索原始记忆。
5. 工具调用需要的 Python、Git、Docker 等外部程序按实际使用的功能准备。若系统提示缺少 WebView2，请先安装对应运行时。

## 本版主要修复

- 摘要树、当前上下文预算回收、跨轮旧记忆清理与来源更正校验。
- 关闭应用时取消并等待后台摘要任务；未完成预览不覆盖完整缓存。
- 桌面 HTTP API 限制来源、主机、方法与 JSON 大小；附件路由限制在附件目录内。
- 修复本次发布检查发现的 Windows Git 临时测试仓库清理问题。

## 使用边界

Token 按统一估算器计量，摘要不能保证无损保留全部信息。父节点保留子分支入口，关键细节可以再查原文；模型自己的陈述不会因此成为经过验证的事实。

本地生成工具以当前用户权限运行。环境变量过滤不等于操作系统隔离；Docker 仅在实际可用并启用时提供对应容器隔离。

本包通过构建记录列出的自动化检查。GUI 操作、真实模型连接和长对话摘要质量尚需实际验收，不标注为已经完成的稳定版验收。

- 修复窄窗口覆盖模式下对话未真正隐藏的问题。折叠中间对话时，右侧工作台直接使用释放的空间。

## 工作区以外的文件与管理员权限
- 文件不在工作区里（如 `D:\共享\月报.xlsx`）时，直接把完整路径告诉 AgentGo。它会先弹出审批卡，写明要访问哪个文件夹；你点“允许”后，这个文件夹在本次运行期间可读写，换别的文件夹会再问一次。拒绝则不会读取。系统目录、凭据目录（`.ssh` 等）、AgentGo 自己的数据目录永远不会放行。
- 命令因权限不足失败时，AgentGo 可以申请用管理员身份重试**这一条命令**（工具 `run_elevated`）：每次都要你在审批卡上点“允许”，Windows 也可能再弹一次 UAC；磁盘分区、关闭防火墙/杀毒、新建管理员账号这类命令不会被执行。AgentGo 不会静默提权，也不会修改 UAC 设置。
- 可以同时开多个会话并行工作；多个会话改同一个文件时没有文件锁，请让它们处理不同的文件。

## 日常使用与排障

- **对话**：双击对话标题（或点铅笔图标）改名；右键对话 → “导出为 Markdown”，生成的文件可用记事本、Word、WPS 打开，只含用户和助手的文字（不含工具调用细节和图片）。
- **操作确认方式**：设置 → 协作方式。严格 = 改文件和运行命令都先问，并且不允许新建工具、委派子智能体、访问工作区以外的文件夹；平衡（默认）= 改文件、运行命令、新建或使用动态工具都先问，访问工作区以外的文件夹也先问；开放 = 在工作区里改文件不再逐次问，但运行命令、申请管理员权限、新建工具、访问工作区以外的文件夹仍然要问。开放模式下改动会直接写入文件，重要资料请先备份。
- **记忆**：记忆面板 → 记忆树，可以看到记忆如何按主题逐层归并，以及某个任务发出时模型实际会读到哪些部分。
- **用量**：设置 → 用量与诊断，按今天、近 7 天、近 30 天看调用次数和 Token；包含记忆整理等后台调用。网关不返回用量时 Token 显示为 0。
- **代码审查**：在对话框输入 `/review`（后面可以写审查重点，例如 `/review 只看错误处理`），AgentGo 会读取工作区里还没提交的改动（包括新建但没有 `git add` 的文件；`.gitignore` 排除的、二进制的、名字像密钥的文件不读），只报这次改动引入的问题，按 P0 到 P3 分级。它只审查、不改文件；工作区需要是 git 仓库，电脑上要装有 Git。
- **项目说明文件**：除了工作区根目录的 `AGENTS.md`，AgentGo 还会读取：工作区所在 git 仓库里从仓库根目录往下每一层的 `AGENTS.md`（某一层没有就用 `agents.md` 或 `CLAUDE.md`）、数据目录里的 `AGENTS.md`（对所有工作区都生效的个人说明），以及 `.cursor/rules` 里的规则（带描述或文件范围的规则只列一个目录，任务相关时才去读）。只想读工作区根目录的，设置环境变量 `AGENTGO_AGENTSMD_PARENTS=0`。
- **用户钩子**：想在智能体运行命令前先拦一道（例如禁止 `rm -rf`）、每轮结束后发通知、给每条消息自动补充信息，可以在数据目录（`%LOCALAPPDATA%`）里放一个 `hooks.json`，写明在什么时机运行你的哪条命令；脚本退出码为 2 就拦截，原因会同时告诉你和模型。设置 → 协作方式 → 用户钩子里能看到是否生效、最近运行了什么、哪里写错了。需要你批准的命令，是批准之后才轮到钩子。钩子是护栏，不是沙箱。写法和示例见同目录下的 `user-hooks.md`。
- **会话分叉**：聊到一半想换个思路试试、又不想丢掉已经聊好的内容时，在左边的对话列表里右键点这条对话，选“从此处分叉”（也可以在对话框输入 `/fork`，或点顶部的分叉按钮；终端界面里同样输入 `/fork`）。AgentGo 会把整条对话连同智能体记得的上下文、协作模式、计划任务清单复制成一条新对话，标题后面加“（分叉）”，原对话保持不变，两边之后各聊各的，删掉一条不影响另一条。新对话顶部写着“分叉自「……」”，点一下就回到原对话。要注意：两条对话仍在同一个工作区里，改的是同一批文件，别让它们同时改同一个文件；对话正在运行、或停在等你批准或回答时不能分叉，先处理完或点停止；智能体在原对话里单独记下的内容（按对话保存的记忆）不会带过去，全局记忆两边共用。
- **运行中**：窗口底部状态栏有一个“运行中 N · 待处理 M”按钮。点开能看到现在有哪些对话正在跑、哪些停在等你批准或回答、哪些后台任务在运行，每一行写着已经跑了多久。点一行就跳到那条对话；点“停止”让它停下，后台任务点“取消”，等你批准的点“去处理”。几个对话同时跑的时候，左边对话列表里的小圆点和这个按钮对得上，刷新页面也不会丢。只显示这个程序里的工作，在别的窗口或别的程序里跑的看不到。刷新页面后，聊天窗口里还在进行的那一轮不会重新显示流出的文字，要看结果，等它结束后点“重新加载会话”。
- **命令的时间与资源上限**：AgentGo 运行的命令默认最多跑 180 秒，超时会连同它启动的所有子进程一起结束；内存上限默认是物理内存的 70%，同时存活的进程最多 256 个（这两项只在 Windows 上生效）。可用环境变量 `AGENTGO_SHELL_TIMEOUT_SEC`、`AGENTGO_SHELL_MEM_MB`、`AGENTGO_SHELL_MAX_PROCS` 调整。
- **出问题时**：设置 → 用量与诊断 → “生成诊断包”，把压缩包发给维护人员。里面有版本、系统、日志末尾、运行参数，密钥和用户名已隐藏；不含对话内容、记忆内容和工作区文件。上次如果是异常退出，这里会有红色提示，诊断包里带有当时的现场记录。

## 数据位置、升级与备份

- 数据直接放在 `%LOCALAPPDATA%` 里（通常是 `C:\Users\<用户名>\AppData\Local`）：`agentgo.db`（对话和记忆）、`config.json`（模型等设置）、`agentgo.log`（日志）。实际位置可在“设置 → 用量与诊断”里看到。
- 升级：关闭 AgentGo，用新版 `AgentGo.exe` 替换旧版即可，数据不动；不要同时运行新旧两个版本。
- 备份：关闭 AgentGo 后，复制 `agentgo.db`（以及同名的 `-wal`、`-shm` 文件，如果有）、`config.json`、`memory-settings.json`（如果有）和 `apps`、`tool_templates` 文件夹。数据目录就是 `%LOCALAPPDATA%` 本身，里面还有别的程序的文件，不要整个复制。
- 回退：从本版起数据库带版本号。以后如果有不兼容的库改动，旧版会拒绝打开新库并弹出提示，不会悄悄写坏数据。本版之前的版本没有这道保护，新旧混用前请先按上面备份。
- 打不开时：桌面版启动失败会弹出说明（例如数据库来自更新版本、缺少 WebView2 运行时），并给出日志路径 `agentgo.log`。没有 WebView2 的电脑请改用浏览器版 `AgentGo-web.exe`。
