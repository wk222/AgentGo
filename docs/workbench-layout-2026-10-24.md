# 工作台与对话布局（2026-10-24）

创作空间保留原左侧位置，主页面为对话、创作空间、任务、扩展和设置。创作空间切到对话后仍保留本次输入与页面状态。

工作台是独立区域，可在任何主页面显示或收起。工作台内部顶部按钮切换代码、记忆、工作流和应用；切换类型不会改变主页面或工作台放大状态。关闭和重新打开工作台保留本次会话已挂载的编辑状态。工作台类型、宽度、主题、对话折叠状态作为布局偏好保存，旧布局会迁移。

中间对话可折叠为窄栏，窄栏显示运行和待审批状态；恢复对话不会重新创建会话。三个区域独立开关，同时收起对话和工作台时显示恢复入口。窄窗口空间不足时工作台作为覆盖面板显示；这部分仍需真实 Windows 界面验收。

工作台标题栏的“将选中对象加入对话”只添加引用，不立即发送。代码引用当前文件；记忆可点击记录后引用，也可直接点击该记录“加入对话”；工作流引用当前流程及选中节点；应用引用当前应用。对象引用只携带类型、ID、作用域、可获得的版本信息和未保存标记，不注入整篇正文。最多同时引用 8 个非传统文件附件对象，标签与字段均截断。既有 @文件 引用入口保留。

引用显示在输入框上方，可逐个移除。切换会话时清除待发送引用。未保存代码和工作流只标记状态，提示智能体先确认保存；不自动上传未保存编辑器全文。对象引用不是新的授权通道，不提供后端版本比较并交换保证；实际读取、修改和审批由原有工具负责。本轮没有新增记忆/流程写入接口，也未宣称已替换 Crush 衍生代码。

代码工作台关闭或显示其他类型时，编辑器全局快捷键不会继续拦截。首次从标题栏搜索文件，通过待处理命令状态等待编辑器挂载，不再依赖抢先发送的键盘事件。
