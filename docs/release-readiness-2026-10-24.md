## 本轮修复

- 记忆摘要后台任务纳入 Runtime 关闭流程，先取消并等待再关闭共享数据库；已完成的语义摘要不再被结构预览降级覆盖。
- 空记忆树清理根节点和检索路由，并在事务内校验来源修订；失败摘要生成增加冷却，避免高频重复请求。
- 本地桌面 HTTP API 校验 Host、Origin、方法和 JSON 请求上限；错误请求不会继续执行。附件通过根目录受限打开，阻止目录穿越，限制活动内容。
- LSP 进程改为拥有整个进程树，退出时关闭连接、回收句柄及后代进程。关闭与启动串行协调，等待启动任务结束；启动失败清理进程，关闭后的 Manager 不再接受启动。
- Windows Git 测试只对自身临时目录清除只读属性，修复对象文件导致的清理失败。
- 发布脚本串联全仓测试、前端检查、生产构建、PE 子系统检查、打包和 SHA256；保留第三方声明并记录待验收项。
